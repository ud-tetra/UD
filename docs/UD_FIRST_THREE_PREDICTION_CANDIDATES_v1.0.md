**CANDIDATE tests:** under the five frozen response laws, V=sum_p omega_p theta_p_plus=0; same formal class must give the same output if the law is memoryless; monotonicity omega<=omega_prime -> q<=q_prime is a tested assumption, not a theorem. ## PRED-03: Finite-scale angular transport memory (priority 92/100)

**Source:** docs/RG_DEPTH_OBSERVABLE_CATALOG_v0.4.md, including the archived GW negative/non-falsifier; 18-vector shell and weak-field studies need current source-provenance refresh.
**CANDIDATE question:** does a K4-derived transport law show a reproducible directional residual and a controlled refinement trend that isotropic and shuffled-orientation null graphs lack?
**Proposed readout:** from a fully specified transport observable P_L(r,Omega), subtract a predeclared radial average, normalize by a declared N_L(r), and extract angular harmonic coefficients a_(ell,m)(L). Compare boundaries, orientations, sizes L, shuffled and isotropic controls. Select the harmonic basis and refinement law *before* holding out data. A finite-resolution geometric harmonic is not a physical force prediction by itself.
**OPEN_GATED:** native generator, exact angular metric, normalization, units, physical coupling/readout and independent replication. No specific measured amplitude, sign, or gravitational-wave effect is claimed. The old GW echo check was a negative/non-falsifying scope adjustment, not a physics success.
**FALSIFIER:** residual or scaling law fails a frozen comparison; isotropic/shuffled nulls yield equivalent signal.
**Next:** construct generator, pre-freeze a source-independent normalization and repeatable refinement controls.
