# Capture protocol

The frozen import scope is the public UD portal source at its captured commit, every current Library title matching UD_, the supplied session project-source attachments, and directly browseable copies of selected manuscript/replay sources. The exhaustive search has no next cursor. The inventory records any mismatch, unavailable file, excluded native Site projection or failed materialization.

Original files are imported as bytes, not executed. SHA-256 deduplication determines duplicate content but does not erase distinct source identities. Library path and current source IDs retain provenance. Historical Library versions not surfaced by the current inventory and unexported chats are outside the recoverable scope.

Archives are deterministic tar/gzip snapshots; split parts are ordered and hashed. A restore verifies them and refuses to replace any existing file. Verification of imported legacy code is inherited unless specifically rerun and logged; ingestion/hash checking is not a scientific replay.

Every future capture uses a new directory and event. Status records distinguish generated, verified, committed and merged. Accepted milestones can reference new manuscripts/claim ledgers, preserving prior versions. Development notes belong on the portal Updates page when portal updates are separately authorized.
