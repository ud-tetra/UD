## Required independent input and sequence

1. An outcome producer other than the historical sign/address selector must emit ordered \(\Theta\) outcomes from independently specified model code or direct same-carrier observations. Commit the producer code/measurement protocol before prediction. For an already produced sealed file, precommit its SHA-256 without exposing its labels. For a future acquisition, freeze the protocol now and hash the outcome immediately when it is acquired. A verbal independence assertion alone is insufficient; an external reviewer must inspect the producer and chronology. Do not use the historical selector to make target labels.
2. `manifest.json` must have `schema="UD-OP03-POLARITY-INTAKE-v0.1"`, `carrier="K4/C1/opposite-pair/Theta"`, `source_version`, SHA-256 strings for `source_computation_sha256`, `pre_event_generator_sha256`, `eligibility_rule_sha256`; `outcome_acquisition_mode="precommitted_file"` with `independent_outcome_sha256` as SHA-256, **or** `outcome_acquisition_mode="future_acquisition"` with `independent_outcome_sha256=null`; `outcome_producer={"kind":"independent_model"|"measurement","artifact_sha256":"...","independence_evidence":"..."}`; `time_parameter="native dimensionless s"`; and `claim_scope="conditional one-pair capacity polarity; no physical promotion"`. Archive the raw source history and code corresponding to these hashes. These fields are declarations; the script checks format and available commitment consistency, not provenance truth.
3. `pre_event.jsonl` contains **every consecutive eligible and control window**, one JSON object per line with a unique `event_id`, `s_start`, `s_end` as canonical exact rational strings, `theta_minus` and `pair_integrity` as three binary values ordered A=(01,23), B=(02,13), C=(03,12), `signed_G_by_pair` as three exact rational strings computed on the ungated source, `prior_event_boundary`, `state_receipt_sha256`, and `eligible_before_outcome` as a boolean fixed without seeing the target. The latter requires an external source-addressability rule, not an outcome-derived event subtype. Record the raw \(c_0,c_1,c_2\), incidence conventions and integration method in the source history so the signed \(G\) can be recomputed independently. No target field belongs in this file.
4. Run `python3 intake.py prepare manifest.json pre_event.jsonl predictions.jsonl freeze.json` in an environment that cannot read the outcomes. It writes aligned, anti-aligned and zero-capacity-change baseline forecasts for all precommitted rows, and hashes the manifest, source file and predictions. The primary stratum requires nonzero signed \(G\), pre-outcome eligibility, both open and closed integrity-passing pairs, and \(w_H(\theta^-)\in\{1,2\}\). No threshold is fitted. Commit the predictions and freeze receipt before the target is made available.
5. `outcomes.jsonl` contains one row per same ordered `event_id` with `theta_plus`, `target_receipt_sha256`, and `producer_artifact_sha256` equal to the committed producer artifact hash. Run `python3 intake.py score manifest.json pre_event.jsonl predictions.jsonl freeze.json outcomes.jsonl`. It refuses a changed manifest, source, prediction, precommitted target hash (when present), row order, or missing record. In future-acquisition mode it records the newly acquired target hash for independent custody review. It reports aligned/anti-aligned capacity-direction matches, non-events/swaps, invalid multi-pair outcomes, and a capacity-persistence baseline. A fixed-Hamming swap is a control, not a polarity discriminator.
