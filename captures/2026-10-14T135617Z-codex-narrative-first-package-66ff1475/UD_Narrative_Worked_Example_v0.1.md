# UD narrative companion: when motion becomes a record

14 October 2026 · Development — no registry entry · Physical promotion: 0

## The story the example tells

Imagine an excitation initially placed in one of two tetrahedra joined along a face. We know where it began. As the state evolves, that initial difference spreads through the complex. What would it take to recover the difference later?

This question gives the geometry a purpose. The shared face specifies a connection between the two cells. The dynamics gives that connection consequences. A calculation tells us how the state moves; a readout determines which part of that motion we can see.

The important surprise is that preserving a difference and displaying it at one location are different things. The entire state can preserve the distinction between two preparations even while a restricted view makes them look identical. Information can become unavailable to a chosen observer without disappearing from the declared closed system.

Memory enters when we want the distinction to remain available to a particular readout. We must specify an interaction that writes it into another state, then ask how long that state remains readable and what resources are needed to maintain it. The coherent tetrahedral flow does not supply that apparatus automatically.

This is a concrete reason for UD's progression from structure to dynamics to records. Structure identifies relationships. Dynamics distributes differences through those relationships. Readout determines availability. Memory is a mechanism for retaining availability under specified conditions.

## 1. Declare the carrier and dynamics

Use the simplicial complex generated by cells 0123 and 0124, with all their faces. Order each simplex by increasing vertex label. Its chain dimensions are

\[
(\dim C_0,\dim C_1,\dim C_2,\dim C_3)=(5,9,7,2).
\]

Let \(d_k:C_k\to C_{k-1}\) be the alternating simplicial boundary. Set \(D=d_1+d_2+d_3\) on the direct-sum chain space and declare the unit-metric real flow

\[
\dot x=Bx,\qquad B=D^{\mathsf T}-D.
\]

The evolution parameter is a model parameter. No physical second, length, or energy calibration is introduced. This is an explicit finite model, not a recovery of the placeholder carrier attachment.

Because \(B^{\mathsf T}=-B\), the propagator \(e^{Bt}\) is orthogonal. It preserves norm and Euclidean distance between any two full-state preparations. This is exact closed-system preservation; robustness under added perturbations is a separate question.

## 2. Ask what the cell readout can see

Let \(q\in\mathbb R^2\) contain the two cell amplitudes. Boundary cancellation \(d_2d_3=0\) gives

\[
\ddot q=-Kq,\qquad
K=d_3^{\mathsf T}d_3=
\begin{pmatrix}4&1\\1&4\end{pmatrix}.
\]

The diagonal entries count the four boundary faces of each cell. The off-diagonal entry reflects the shared face with the declared orientations. A change of basis orientation changes amplitude signs consistently, not the spectrum.

The symmetric mode \((1,1)\) has frequency \(\sqrt5\); the antisymmetric mode \((1,-1)\) has frequency \(\sqrt3\). For the full 23-dimensional flow,

\[
\det(\lambda I-B)=\lambda(\lambda^2+3)^4(\lambda^2+5)^7.
\]

These are consequences of the declared architecture and flow. They are not particle identities or calibrated physical frequencies.

## 3. Demonstrate preserved distinction and temporary readout loss

Prepare either \(L\) or \(R\), with equal prior probability:

\[
q_L(0)=(1,0),\quad q_R(0)=(0,1),\quad \dot q_L(0)=\dot q_R(0)=0,
\]

and set all other initial chain coordinates to zero. Define \(c_5=\cos(\sqrt5t)\) and \(c_3=\cos(\sqrt3t)\). Then

\[
q_L(t)=\tfrac12(c_5+c_3,c_5-c_3),\qquad
q_R(t)=\tfrac12(c_5-c_3,c_5+c_3).
\]

Their cell-only distance is

\[
\|q_L(t)-q_R(t)\|=\sqrt2\,|c_3|.
\]

At \(t_* =\pi/(2\sqrt3)\), the two cell snapshots coincide. An observer given only these noiseless cell coordinates at that time cannot identify the initial alternative; equal-prior guessing error is \(1/2\).

Yet the full-state distance remains \(\sqrt2\). In particular,

\[
\dot q_L(t_*)-\dot q_R(t_*)=-\sqrt3(1,-1),
\]

so retaining the cell derivatives distinguishes the alternatives. The missing distinction is present in the coupled state, rather than accessible in the chosen cell snapshot.

Away from the zeros of \(c_3\), exact noiseless cell coordinates distinguish the alternatives perfectly. The shrinking distance alone is not a smooth information-loss law. A quantitative noise model or finite-resolution rule is needed before converting distance into a gradual error or information curve.

## 4. Declare the memory addition honestly

As a logical benchmark, suppose a readout at preparation identifies a bit \(z\), with \(L=0\), \(R=1\). Add a memory bit \(m\), initially blank, and the reversible write map

\[
(z,m)\mapsto(z,m\oplus z).
\]

With \(m=0\), the memory holds \(z\). If its post-write rule preserves that bit, it can identify the preparation even at \(t_*\), when the cell snapshot cannot.

This specifies the desired logical action. It does not derive a native local carrier-to-memory interaction. The map assumes access to \(z\), a blank memory, a write operation, and a retention rule. Those assumptions must become explicit apparatus dynamics before this benchmark counts as an implemented UD write mechanism.

For illustration, if a declared retention channel flips the memory with probability \(p\in[0,1/2]\), then

\[
P_{\rm error}=p,\qquad I(Z:M)=\ln2-h(p),
\]

where \(h(p)=-p\ln p-(1-p)\ln(1-p)\). The memory marginal entropy remains \(\ln2\) for the uniform source even as retained source information falls. Consequently marginal entropy alone is insufficient to measure record quality.

## 5. Explain why cost and entropy need their own derivations

A reversible logical map does not specify a physical energy cost. The complete apparatus must declare carrier and memory energies, interaction switching or autonomous control, readout, blank-memory preparation, retention, and environmental renewal. Without those definitions, there is no complete resource denominator for an information-efficiency claim.

Likewise, the joint distribution above supplies operational information quantities; it does not by itself supply thermodynamic entropy production. Face counts do not supply physical area. A retained-information-per-area claim requires a declared physical area map and a derived capacity or scaling law. A gravitational entropy normalization requires a further bridge.

## Reproducible verification code

Requires Python and SymPy. Verification run: PASS for every assertion.

```python
from itertools import combinations
import sympy as s

cells = [(0,1,2,3), (0,1,2,4)]
simplices = [sorted(set(face for cell in cells for face in combinations(cell, k+1))) for k in range(4)]
boundary = {}
for k in range(1,4):
    d = s.zeros(len(simplices[k-1]), len(simplices[k]))
    for j, face in enumerate(simplices[k]):
        for r in range(k+1):
            d[simplices[k-1].index(face[:r]+face[r+1:]), j] = (-1)**r
    boundary[k] = d
assert boundary[1]*boundary[2] == s.zeros(5,7)
assert boundary[2]*boundary[3] == s.zeros(9,2)
offset = [0]
for group in simplices:
    offset.append(offset[-1]+len(group))
D = s.zeros(offset[-1])
for k,d in boundary.items():
    D[offset[k-1]:offset[k], offset[k]:offset[k+1]] = d
B = D.T-D
assert B.T == -B
x = s.symbols('x')
expected = x*(x*x+3)**4*(x*x+5)**7
assert s.expand(B.charpoly(x).as_expr()-expected) == 0
K = boundary[3].T*boundary[3]
assert K == s.Matrix([[4,1],[1,4]])
assert K*s.Matrix([1,-1]) == 3*s.Matrix([1,-1])
assert K*s.Matrix([1,1]) == 5*s.Matrix([1,1])
print('PASS: f=(5,9,7,2); boundary squared zero; skew flow; characteristic polynomial; cell oscillator; symmetric/antisymmetric modes.')
```
