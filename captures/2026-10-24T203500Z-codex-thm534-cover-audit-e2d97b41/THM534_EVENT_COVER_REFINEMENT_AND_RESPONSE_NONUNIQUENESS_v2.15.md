## 1. What is being audited

The v2.14 activity-margin response is defined for a specific candidate event cover, one block per tetrahedron. It preserves the original real norm and signed ownership receipts and is Lipschitz at fixed permissions. Those results do not establish that the response is determined by the summed native generator independently of event presentation. This note tests that additional property and isolates the remaining actuation normalization choice.

Retain the original real field, unit support metric, incidence operators, fixed hard face permissions and Q177–Q179 ownership. Q169 gives unique native simplices; Q173 gives whole-face stars. Their uniqueness is actual source structure. The cell-centered collective grouping used below is an additional candidate event alphabet, not a new set of native simplices. No source is claimed for treating arbitrary indexed copies as distinct physical events.

H_\tau^h=\sum_{f\subset\tau}\frac{h_f}{k_f}G_f,
\qquad \sum_\tau H_\tau^h=A_{23}^h,
\qquad C_H(t)=(I-tH/2)^{-1}(I+tH/2).
\tag{1}
\]

At reference step one, the v2.14 rule uses

s_i=\|(C_{H_i}(1)-I)x\|^2,\quad

with zero extension at empty read stock. Conflict means overlapping declared event footprints. Positive-weight events execute \(C_{H_i}(w_i)\). The fixed-cover rule has no added record register; its objective, cover and model convention remain candidate choices.

## 2. A generator-preserving refinement that defeats indexed strict comparison

For an integer \(m\ge2\), replace each indexed block \(H_i\) by \(m\) indexed copies

\[
H_{i,r}=H_i/m,\qquad 1\le r\le m.
\tag{3}
\]

Give each copy the same declared footprint as its original block and define conflicts by footprint overlap, including conflicts between copies. This is an extension of (2) to a different indexed event presentation. It is not the one-block-per-cell domain of the original theorem.

**Theorem P1 (indexed-clone stall).** The refined generators satisfy

\[
\sum_{i,r}H_{i,r}=\sum_iH_i,
\tag{4}
\]

but every strict margin in the indexed refined rule is zero for every field state. Its state update is the identity, independently of any positive score normalization.

**Proof.** Equation (4) is linear. Each copy has a conflicting twin with the identical operator, reference score and footprint. The competitor maximum is therefore at least its own score, so its strict positive margin vanishes. Dividing zero by another positive resource normalization cannot create a winner. Zero-stock cases already use the identity extension. \(\square\)

Thus a rule of this indexed strict-margin form is not invariant under generator-preserving cloning. This does not retract a fixed-cover conservation or locality result. It refutes an inference that the summed generator and metric alone determine that response for arbitrary event presentations. If a native law distinguishes physical events from bookkeeping copies, it must state which event identity/grouping is admitted. If the copies represent genuinely distinct physical alternatives, symmetry-breaking data or a joint event may be required, rather than a bookkeeping quotient.

## 3. Activity is not an additive event cost

Even before comparison, metric activity is nonlinear in a generator. For one native private face/core pair with

\[
H=\begin{pmatrix}0&-1\\1&0\end{pmatrix},\qquad x=(1,0),
\]

the unit Cayley event gives

\[
C_H(1)x=(3/5,4/5),\qquad A_H(1)=4/5.
\tag{7}
\]

Each half-generator reference event gives \((15/17,8/17)\), with activity \(4/17\). Therefore

\[
2A_{H/2}(1)=8/17\ne4/5=A_H(1).
\tag{8}
\]

For general skew \(H\) and fixed \(x\), the resolvent identity yields

\[
A_{H/m}(1)=\frac1{m^2}
\left\|(I-H/(2m))^{-1}Hx\right\|^2,
\quad
mA_{H/m}(1)\le\frac{\|Hx\|^2}{m}\longrightarrow0.
\tag{9}
\]

Even the instantaneous diagnostic \(Q_x(H)=\|Hx\|^2\) obeys

\[
\sum_{r=1}^m Q_x(H/m)=Q_x(H)/m,
\tag{10}
\]

so a nonzero quadratic diagnostic cannot simultaneously be additive under this linear refinement without additional weights or a different resource definition. These identities concern diagnostic aggregation, not a prohibition on all native action principles.

A second distinction is necessary: Cayley events do not form an exact time-subdivision semigroup. In this same pair,

\[
C_{H/2}(1)^2x=(161/289,240/289)
\ne(3/5,4/5)=C_H(1)x.
\tag{11}
\]

Both outputs have norm one. Thus equality of generator sums does not guarantee equality of finite Cayley schedules. P1 is an audit of a proposed presentation invariance, not an assertion that all such finite schedules describe the same physical experiment.

## 4. A continuum of admissible response magnitudes

**Theorem P2 (normalization nonuniqueness).** In the fixed v2.14 cover, replace the denominator \(4E_i\) by \(cE_i\), for any fixed dimensionless \(c\ge4\). The same positive-weight set is selected. The norm, signed receipts, covariance, bounded reads and fixed-mask Lipschitz conclusions still hold with the previous sufficient bounds. Nevertheless the outputs differ on the strict-margin preparation (5) as \(c\) varies.

**Proof.** The weights scale as \(w_i^{(c)}=(4/c)w_i^{(4)}\). They remain in \([0,1]\) and keep the same disjoint positive supports. The local Cayley events retain orthogonality and their exact midpoint receipts at the new actual steps. Both the weight and its derivative shrink by \(4/c\), so the previous sufficient regularity bounds are not increased. Source geometry and covariance are unchanged.

At (5), the selected step is

\[
w_0^{(c)}=\frac{32}{357c}.
\tag{12}
\]

For a fixed skew block, commuting resolvents give

\[
C_H(t)-C_H(s)=
(t-s)(I-tH/2)^{-1}H(I-sH/2)^{-1}.
\tag{13}
\]

If \(Hx\ne0\), this difference applied to \(x\) is nonzero whenever \(t\ne s\). The resolvents are invertible and commute with \(H\). Thus distinct \(c\) produce distinct outputs on (5). \(\square\)

The number four in v2.14 is a sufficient spectral normalization, not a uniquely derived actuation coefficient. Additional maximality, resource-cost or renewal assumptions could distinguish members of this family, but conservation and continuity do not provide those assumptions. This nonuniqueness concerns event magnitude even where the winner itself is unchanged.

## 5. Disposition and concrete next requirement

The fixed-cover v2.14 proofs remain in force. This audit adds two explicit requirements before calling its policy a derived native selector or an action-unit map:

1. Identify the physical/native event alphabet and explain why the selected grouping is used. If a change is only a presentation refinement, specify the quotient or refinement law before applying score competition.
2. Supply an event-resource or renewal law that fixes actuation magnitude and aggregation. A metric displacement diagnostic and a sufficient denominator bound do not do this alone.

Quotienting exact indexed clones can repair the specific P1 artifact, but it is an additional representation rule and does not identify all possible regroupings. Nor does it resolve P2, symmetric stalls, hard readiness, asynchronous commit, outgoing records or reset. The native unique-simplex structure may constrain allowed primitives; passing from those primitives to collective bulk events still needs a source rationale.

Q153/Q156/G05 remain open at constitutive flux, permission/conductance and action/renewal levels. No new physical coefficient, action quantum, clock, particle/quark/lepton map or empirical validation is inferred. The next test should apply an explicit native event-cost proposal to (7)–(12), preserving the indexed-copy and normalization controls as discriminants rather than fitting a physical target.
