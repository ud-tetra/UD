5.2 Correction 2 & 3: Variational Sequencing with Module-Specific GapsFor each stored Ritz pair $(v, \tilde{\lambda})$, the evaluation computes the Rayleigh quotient, residual vector, residual variance, and the Lehmann-Maehly enclosure against the module-specific gap lower bound $\gamma_m$:   Pythondef evaluate_variational_enclosure(A_module: np.ndarray, v: np.ndarray, lambda_solver: float, gamma_module: float):
    """
    Computes variational statistics before inspecting solver return.
    A_module: Stored binary64 matrix for the specific module.
    v: Normalized stored Ritz vector (||v||_2 = 1).
    lambda_solver: Scaled eigenvalue returned by the numerical eigensolver.
    gamma_module: Certified lower bound on the isolation gap for THIS module.
    """
    # Step 1: Normalize vector
    norm_v = np.linalg.norm(v)
    v_norm = v / norm_v

    # Step 2: Compute Rayleigh quotient theta = <v, Av>
    Av = A_module @ v_norm
    theta = float(np.dot(v_norm, Av))

    # Step 3: Compute residual vector r = Av - theta*v
    r = Av - theta * v_norm

    # Step 4: Compute residual variance eta^2 = ||r||_2^2 = ||Av||_2^2 - theta^2
    norm_Av_sq = float(np.dot(Av, Av))
    eta_sq = norm_Av_sq - (theta ** 2)
    eta = np.sqrt(max(0.0, eta_sq))

    # Step 5: Validate isolation gap condition
    assert gamma_module > theta, f"Gap collapse: gamma ({gamma_module}) <= theta ({theta})"

    # Step 6: Derive Lehmann-Maehly / Temple interval enclosure for true eigenvalue
    # Interval half-width: Delta = eta^2 / (gamma_module - theta)
    enclosure_half_width = eta_sq / (gamma_module - theta)
    enclosure_interval = (theta - enclosure_half_width, theta + enclosure_half_width)

    # Step 7: Compare against solver return lambda_solver
    solver_return_error = abs(lambda_solver - theta)

    # Step 8: Evaluate frozen scaled residual check
    # Scaled residual: ||r||_2 / max(1, ||A||_inf + |theta|) <= 5e-12
    A_inf = float(np.max(np.sum(np.abs(A_module), axis=1)))
    scale_factor = max(1.0, A_inf + abs(theta))
    scaled_residual = eta / scale_factor
    scaled_tolerance_passed = (scaled_residual <= 5e-12)

    return {
        "rayleigh_quotient": theta,
        "residual_variance": eta_sq,
        "residual_norm": eta,
        "module_gap": gamma_module,
        "enclosure_half_width": enclosure_half_width,
        "enclosure_interval": enclosure_interval,
        "solver_return_error": solver_return_error,
        "scaled_residual": scaled_residual,
        "scaled_tolerance_passed": scaled_tolerance_passed
    }
