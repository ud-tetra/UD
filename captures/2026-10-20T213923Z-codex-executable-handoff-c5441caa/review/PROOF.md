# C22 conditional orchestration proof

Let D be the frozen dependency map and I the complete explicit manifest/input byte bundle. Assume stable intended inputs and dependencies during the run, faithful invocation, and correctness of the pinned child tools on the intended byte bundle. Let S be a valid identity report bound to the projected record and fixed catalog, N a certified numerical report with all required gates and exact intended manifest/payload/witness/protocol bindings, and A a distinct auditor PASS report bound to that same manifest, numerical certificate and witness, with every required exact matrix/scalar check passing.

The orchestration acceptance predicate must be a conjunction: dependency/input endpoint equality AND valid S AND valid N AND valid A AND consistent cross-report identities. A child's exit code alone is insufficient: the auditor can return zero while its report is HOLD. Likewise, a status string alone is insufficient when gates, required files, scope flags or hashes disagree. If each term is explicitly checked before returning NUMERICAL_PASS_PROVENANCE_HOLD, that terminal state entails the conjunction for the observed fixed bundle. It does not prove the underlying numerical theorem without the child-tool premises; the independent auditor supplies finite distinct product/scalar evidence rather than replacing every premise by the producer's own assertion.

The state graph is acyclic: preflight -> identity -> numerical -> auditor -> final content/binding check. Each transition requires the previous content checks. Numerical HOLD is terminal before auditor invocation; any continuation or retry would violate the handoff contract. A rejected preflight must occur before creating the new output directory. An error after creation may preserve an incomplete auditable run, but cannot be labelled numerical-pass.

The numeric identity format types only matrix dimensions and exact rational entries. A listed fingerprint is not proof of replay, and an unlisted fingerprint is not proof of acquisition independence. Conditional on two admissible histories yielding the same projected matrix with different independence labels, any function of that matrix or its fingerprint cannot distinguish both correctly. No actual independent replicate is asserted. Computationally changed inputs can be unlisted without acquisition. Units, coordinate basis, channel meaning, projection definition, raw acquisition, preparation and hidden-state history require their own evidence; catalog matches cannot merge that evidence.

Consequently the successful workflow retains independent_acquisition and fresh_preparation NOT_ESTABLISHED, provenance HOLD, external review PENDING and Physical Promotion = 0. Child spectral acceptance is acceptance of supplied projected numerical bytes and factors, not acquisition or physical acceptance. Inherited identity/spectral contracts remain separately scoped; orchestration creates no transfer of physical authority and no new estimator call. Endpoint hashes do not supply a universal race-proof snapshot. All-input backend/whole-program guarantees remain OPEN.
