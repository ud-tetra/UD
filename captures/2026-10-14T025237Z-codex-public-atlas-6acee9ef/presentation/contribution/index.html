Contribution

Help make the next result checkable.

Mathematicians, scientists, independent peer reviewers and research software contributors are invited to take on a bounded task.

01

Choose a concrete contribution.

MATHEMATICS

Check a proof.

Review one exact spectrum, reconstruction premise or interface obstruction. Identify missing steps and counterexamples.

RESEARCH SOFTWARE

Reproduce a calculation.

Run a named replay in a fresh environment. Record the version, inputs, commands and differences.

EXPERIMENTAL SCIENCE

Qualify one bridge.

Define the observable, measurement, calibration, custody and null comparison before exposure.

SCIENTIFIC EDITING

Repair a source chain.

Recover an original equation, clarify units, improve notation or document a version conflict.

02

A useful first review.

  1. Name the artifact and version.
  2. State the exact hypotheses and scope.
  3. Return proof notes, a counterexample, code or a reproduction receipt.
  4. Distinguish what passed from what remains unresolved.
  5. Agree attribution and publication of the review summary.

A review of one result does not endorse the whole framework. Reviewer compensation, if separately agreed, is for careful work regardless of conclusion.
