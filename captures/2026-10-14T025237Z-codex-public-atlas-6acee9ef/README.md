# Unified Dynamics public research atlas

Public reading edition 0.1. This project is a presentation layer with preserved source status. Physical promotion 0. Independent human review pending.

Static entry point: dist/index.html. Routes are ordinary HTML directories. No visitor sign-in, tracking, external scripts or service integrations are needed. Source search indexes the current public portal records, GitHub file metadata, attached source intake and a scientific memory crosswalk. The coefficient view retains original source status and next gates. Raw internal/patent notebooks are not published.

Source baselines: portal commit 44228e7eb906cd230ba3f0989dd73ffff8812da8 and ud-tetra/UD commit 47121c4b2d8f472c4eaa977b475d20cc267eed3d. See dist/assets/coverage.json for intake scope, missing files and limitations.

Verification: run python verify_core.py, node --check dist/assets/app.js, then python check_site.py. No Python dependencies are required. The math check uses integer characteristic polynomials and exact rational elimination for three finite carriers and the rank-18 ambient difference, not every assertion in the source collection. Rendered browser QA was unavailable in this managed runtime.

build.py documents the creation pipeline and requires the declared source snapshots and attachment intake. The built dist directory is preserved in the source repository so deployment does not depend on scratch paths. Do not execute imported archived scripts merely to ingest a source. Copy prior input versions when reconciling a new scientific amendment; never alter their original statements silently.
