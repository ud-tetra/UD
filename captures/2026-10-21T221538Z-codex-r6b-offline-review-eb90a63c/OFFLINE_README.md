# R6b offline review bundle

Extract the ZIP into a new directory. With Python3 and NumPy available, run from that directory:

```bash
python3 verify_offline.py --output REVIEW_RUN.json
```

No network, git executable, checkout or fetching is required at execution time. The bundle contains the44 inventoried evidence files from six pinned captures, their six original manifests, and three separately pinned source files. Input arrays are already staged in the original NPZ containers. The wrapper validates hashes and executes seven explicitly selected fresh constructor verifiers in temporary copies. It never executes recovered docs scripts or calls an eigensolver.

The original exact PR358 audit handles module-specific beta bounds, exact rational trial variance, frozen full512-coordinate stored-return residuals and inter-module mixtures. Six regenerated exact/assembly JSON results must match the pinned originals. The existing numerical payload verifier is judged against its original frozen thresholds. Do not substitute the proposed full-matrix function with a single module gap.

The bundle was tested with Python3.12.14 and NumPy2.3.5. SciPy and SymPy are not needed for these seven verification calls. Install dependencies before moving it into an offline runner. This package does not supply a Python runtime or an offline NumPy wheel.
