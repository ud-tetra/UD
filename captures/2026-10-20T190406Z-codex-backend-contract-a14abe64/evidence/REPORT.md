## Checks and limitations

`audit.py` rechecks all pinned source hashes and literal scope disclosures, the 128-entry crosswalk and 14 requested roles, all 38 delta paths, exact issue snapshots, selected return-status passages and zero-comment responses. The first draft’s source inspection labels were clarified to preserve semantic-read labels through later hash inventory and to describe the targeted issue screening precisely. Original draft source/output and the correction receipt are retained; the candidate classification and scientific conclusions did not change. Five content-triage controls ensure that a PASS filename/label, self-asserted execution/review fields, or an empty/unknown document cannot become a qualified empirical return. This script is deliberately not an evidence authenticator: unknown documents remain unverified, and scientific truth/authority acceptance require actual content review.

Reproduce without numerical fitting:

```bash
PYTHONDONTWRITEBYTECODE=1 python audit.py --repo /absolute/UD --out /absolute/new-audit.json
```

Repository and issue data are pinned to this audit. Later issue edits or new evidence require a new bounded audit, not rewriting this one. The source-capture mathematics was not rederived here. Same-team content review does not replace external promotion review or custodian ruling.
