# Replay of the four-case full contract

The package directly includes every frozen input, source structure, graph helper, potential/plugin byte, stationary input/basis array, plugin source/license and numerical script required by this new full calculation. The immutable UD_GRAPHITE_SAFE_STENCIL_FIVE_PROBE_AUDIT_v0.1.zip is retained as historical evidence; extracting its nested archives is optional and unnecessary for replaying this new run. No archive script is executed during ingestion. Keep original outputs untouched and use a separate replay directory.

Use compatible LAMMPS Python distribution2025.7.22.4.0, matching MPI and NumPy. Shared libraries and environment are declared in run.py; these are numerical research runtime paths, not account configuration. A different plugin build must have its new identity recorded explicitly in a replay receipt, rather than silently changing the frozen original. Source-tag to runtime-binary identity has the limitation recorded in the preserved source audit. longdouble precision is platform dependent; this Linux run has63 explicit mantissa bits.

FREEZE.json declares the full contract; PRECHECK_SEAL.json identifies geometry/input plans made before forces. CODE_FREEZE.json was emitted after preflight and before fresh force collection. prepare.py is preserved provenance and must not overwrite supplied frozen records. In a separate replay, run the preflight, freeze the new identities, then run.py. It launches four local case processes with one numerical thread each. analyze.py reconstructs full matrices and tests every gate; verify.py recomputes the plans, raw differences, spectra, full flags and complete failed-column sets.

All reconstructed coordinates use common.positions: extended-precision affine sum, one rounding to native float64. PLAN.npz preserves nominal vectors, all selected steps, representation error metrics and sampled branch flags; actual stencils can be reconstructed from the immutable stationary input. RAW.npz preserves all force pairs, derivative arrays, reversed middle pairs and baseline forces. HESSIANS.npz holds the three full matrices, retained symmetric middle matrix and eigenvalues. Passing status is in RESULTS.json, not inferred from a filename.

Units: Angstrom for coordinates/steps, eV/Angstrom for projected force, eV/Angstrom^2 for stiffness. No physical clock, reservoir, damping or friction coefficient is identified by this numerical qualification.
