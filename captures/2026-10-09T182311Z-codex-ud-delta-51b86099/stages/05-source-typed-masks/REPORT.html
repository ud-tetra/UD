Provenance and model

The supplied historical coefficient ledger v0.39 records Q173, the face-indexed current J23^h=2 h_f B3_{f,tau} c2_f c3_tau, with 128 binary masks verified on the two-tetrahedron A pair. It also records Q167, the edge-indexed current J_ie^S=2 h_e D_ie x_i y_e, with 64 binary masks verified. Q167's verification is six edges on the single-tetrahedron carrier; extending one mask to each of the nine edges of the paired carrier is a new conditional extension tested here, not an existing ledger theorem. Q169 fixes a global skew Hodge–Dirac on unique simplices. This audit uses those typed indices, increasing orientations, unit metric, and A=Bᵀ−B.

For each face f, its one control Lf sums all its face–cell incidence rotations. For each edge e, its one control Le sums both vertex–edge incidence rotations. Other couplings remain unit strength. A mask dynamically modifies the skew generator, not the original boundary operator or topology. It is not asserted that Q167 and Q173 must switch independently in a UD source law; the combined family is a deliberate mathematical stress case consistent with their typed objects. The source laws that select mask values and switching times remain open.

Why twenty-three disappeared

The previous 23-coordinate result independently switched just one end of a vertex–edge incidence. A whole-edge mask acts on both ends with the same coefficient, so it annihilates the uniform vertex vector. The global A and every permitted whole-face and whole-edge mask also annihilate that vector. The row-space calculation gives dimension 22 for the combined family, leaving exactly that one-dimensional direction unobserved.

Switching a single end still exposes the uniform vector and reaches 23, but that operation belongs to a different control grammar. Nothing in the cited Q167 mask formula establishes independent half-edge control. The 23 result remains valid as an adversarial stress test, not the ceiling of this source-typed family.

Exact proof and limits

Beginning with the same six-dimensional cell/shared-face record, rational row reduction repeatedly adds O A and O L for each allowed mask generator L. The fixed point is the least common invariant row space. Each final basis is verified by exact intertwiners O A=HA O and O L=HL O. This proves the minimum dimension among common autonomous linear records for all real initial states and all prescribed mask values, including piecewise-constant schedules with locally finite switching and no resets. For the seven face masks, the final row space agrees exactly with the prior fourteen-coordinate all-face–cell space. For the combined family the uniform vertex mode spans the remaining kernel.

These results do not derive admissibility predicates, timing, a physical clock, a quantum model, or computational speedups. If eligibility uses omitted state or masks cause jumps, additional variables or receipts may be necessary. If UD imposes dependencies among face and edge masks, smaller records could exist; such restrictions must have independent source provenance.
