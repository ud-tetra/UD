# Append-only proof ledger

One unique JSON entry per proved milestone, version and status. Each entry links a theorem-quality proof, source versions and the verification receipt. Corrections require a new version and a supersedes link.

Initial entries: UD-PM-PRED01-001_v1.0.json and UD-PM-PRED02-001_v1.0.json.

This is an explicit seed ledger, not a retrospective audit of every historical theorem. Review and physical correspondence are separate statuses. Archive information is not proof authority.
