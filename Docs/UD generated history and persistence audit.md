## What persistence means here

For a nonuniform current state x=b-mean(b), let N=norm(x) squared. With one matching closed, the contrast spectrum has rates 1/2,1/2,1. For a frozen current gate, the slow spectral weight is Wclosed(current)/(2N). If g_current is the change in the instantaneous quadratic relaxation score caused by a swap:

```text
Delta slow weight = -2*g_current/N
M_after(current,s)-M_before(current,s)
 = Delta slow weight*(exp(-s/2)-exp(-s))
```

This compares two hypothetical future propagations with their before/after gates held fixed and the same current state. It is not a claim that the actual switching future follows either frozen operator. Every observed swap in this sweep has positive current gain, so it strictly lowers this frozen current-memory measure at every finite s>0. A singleton window guarantees this analytically; other windows have only the stated bounded evidence here.

Actual source-free propagation contracts contrast regardless of how the Hamming-one gate sequence is selected. Each exact replay step checks:

```text
z^4*N_before <= N_after <= z^2*N_before
```

Therefore norm(x(s))<=exp(-s/2)*norm(x(0)) for every Hamming-one switching sequence. If total elapsed source clock diverges, all nonuniform contrast vanishes. Continuing swaps, historical score retention and permanent nonuniform burden retention are different claims. Uniform burden survives by conservation; it is not evidence of a localized cluster.
