# UD Mainline Bootloader v1.0 — Agile Research Gate

1. Verify repository revision, active branch, contributor authority, and applicable AGENTS.md workflow.
2. Read [UD-SCOPE-001](docs/governance/UD-SCOPE-001-observable-domain-falsifiability.md) and [UD-AGILE-001](docs/governance/UD-AGILE-001.md) before deriving or publishing claims.
3. Identify hypothesis ID/version, prior target exposure, admitted mathematical primitives, assumptions, and evidence status.
4. Treat outside proposals (including Gibsonian Mathematics) as attributed inspiration only; independently derive all UD conclusions and disclose imported assumptions.
5. Separate EXACT / DERIVED / CONDITIONAL / HYPOTHESIS / FIT / NUMERICAL / EMPIRICAL / NO-GO / OPEN; never promote numerical agreement alone.
6. Predeclare observable, scale, normalization, uncertainty, comparator, and falsifier before physical testing. Physical Promotion = 0 until independently audited evidence satisfies the bridge.
7. Execute REGISTER -> DERIVE -> CHALLENGE -> TEST -> DECIDE -> PROMOTE; RETAIN / REVISE / REJECT / HOLD with versioned receipts.
8. Preserve original artifacts, use isolated contributor branch, capture manifest/event, run repository verification, and submit a PR. Never claim unexecuted checks passed.

Boot report: repo SHA; branch/session/claim; policy versions; hypothesis ID; source/target exposure; exactness/units; claim boundary; next falsifier; test status; blockers.
